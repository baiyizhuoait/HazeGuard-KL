## 十个关键决策

1. **删北京**。文档原要求 UCI 北京作跨气候压力测试，但项目组决定只做 KL；
   泛化实验改为域内 LOSO + 时间外推 + 季风切片。
2. **把"8 个监测站"改成"26 个互异格点"**。这是被数据逼出来的：8 个坐标只有 3 组逐位相同的序列。
   不改，上风向特征和 LOSO 都是假的。
3. **空间单元用格点，不冒充监测站**。报告里不出现 "measured at station"。
4. **气候态基线只在 train 上算**，按 (station, month, hour) 统计后广播，防泄漏。
5. **主实验只在 3 个受体节点训练**。走廊和源区只作特征输入；混进来会把高危先验从 12.21% 稀释到 3.37%。
6. **指标体系定死六项、一套实现**，谁都不许另写；`High_Risk_Recall` 用 union 口径（预测落在 {2,3}）。
7. **删掉 GPSO、SHAP、分位数森林、模糊 C 均值**，换成课内等价做法；只保留有序 RF，且实测输给回归切档，进附录。
8. **保留 v1 特征表作为官方**，v2（补 `hour_cos`）只做对照 M8。
   理由：M2~M7 的成绩都基于 v1，换表要全链路重跑；缺陷影响已量化（+0.0046 / −0.0311）。
9. **M8 测试集只跑一次，不换环境重跑**。环境差异 0.0005 / 0.0007，与种子噪声同量级；
   写明环境比换环境重跑更有价值。
10. **纪律自动化**：完整性 17 项、合并闸门十项、文字自查、数字溯源四把脚本。
    规则要能跑，才有人守。

## 11-15 深夜：7 号复核 M1，补四处实现错误

7 号在 `8f9cd74` 上查出 M1 的四个问题，复核后全部成立，已修：

1. **默认调参路径仍在泄漏**：不传 `--fixed-params` 时走 `GridSearchCV(cv=TimeSeriesSplit(3))`，
   按行切折且输入按节点排列，实测训练集包含验证期之后的样本；内层也不重算气候态。
   处理：默认固定参数，`--search` 直接报错退出（KD-05），恢复条件写在报错里。
2. **最终训练与验证/测试的预处理不一致**：`look_all` 只用于训练，val/test 沿用面板列。
   实测 60 / 95 行不同，最大差 0.21324 µg/m³。处理：拟合一次气候态，train/val/test 共用，
   连同 `preprocess.sha256` 存进模型。
3. **主表模型没保存**：`model_e`（可建模行）只出指标不落盘，指标与产物不是同一个对象。
   处理：主表模型存为 `baseline_dt.joblib`（含预处理与 `trained_on`），全行模型另存
   `baseline_dt_allrows.joblib`；两模型逐行差异由脚本计算写入 `eligibility.vs_all_rows_diff_rows`
   （当前 451 行、最大等级偏移 2），不再写死字符串。
4. **末折漏尾、边界自检只打印**：`_folds_by_timestamp` 末折改闭区间；边界越界改成抛错。

顺带发现并修掉一处：气候态原先只用「特征齐全」的训练行估计，和面板 `b_proto` 口径不同，
导致模型特征与面板列差 460/60/95 行。现在用受体 train 段全部行，三方逐值一致（差 0）。

结果：CV 0.6277（std 0.0107，5 折 0.6230/0.6301/0.6335/0.6419/0.6102），
六项测试指标不变（0.6658 / 0.6473 / 0.7675 / 0.3199 / 0.0210 / 0.9047），树 385 叶、深 9。
新增 `tests/test_stage1_baseline.py` 6 项（禁用搜索、末折覆盖、边界抛错、单份预处理、
模型复载复现指标、模型特征与面板列一致），全套 108 项通过。
