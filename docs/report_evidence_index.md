## 3. 三处必须照实写的负面或保守结果

1. **M1 打不过持续性**：高危召回 0.7675 < 0.7757。训了模型反而更差，这是后续所有复杂度的立项依据。
2. **空间与邻域特征都没有增益**：12 段消融里空间加权 0.7125 → 0.7103，邻域 50 列 0.7157 → 0.7078；
   Top-25 里 `upwind_pm25_advection_1h/2h/3h` 一个都没进。报告里写"未在分类器上复现"，
   不要写"空间信息无效"——7 号在回归设定下测到过增益，两件事不能混。
3. **M8 在测试集上是打折的好消息**：Macro-F1 +0.0031、代价 −0.0372，但高危召回 −0.0018、
   跳级 +0.0015；区间测试覆盖 87.97%，低于名义 90%。两处都要写，不能只报有利的一半。

  写完自己念一遍。
